Embedding a Forgeboard gallery

This file is deliberately not served by Forgeboard. Open it straight from disk (file://) or from any other local web server, so the embed is exercised as a genuine third-party host rather than same-origin.

Paste this snippet into your own page:

<iframe
  src="http://localhost:3000/embed/autumn-build-2026?limit=12"
  title="Project gallery"
  loading="lazy"
  style="width:100%;height:620px;border:0"
  referrerpolicy="no-referrer"
  sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox">
</iframe>

The embed shows submitted projects only. Drafts, scores, judge identities and vote totals are not in the payload at all, so there is nothing private to leak through the frame.
